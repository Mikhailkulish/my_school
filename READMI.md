# my_school
Проект представляет собой сервер учебного центра, разработанный с помощью фрейм-ворка Django REST (DRF).
## Установка и использование
Чтобы установить и запустить проект, нужно выполнить следующие действия:
* клонировать репозиторий, использовав ссылку с аккаунта GitHub;
* установить фреймворк Django;
* установить надстройку REST;
* активировать виртуальное окружение;
* запустить приложение через модуль manage.py.
### Особенности реализации
Проект реализован по концепции CRUD с реализацией отображений и использованием сериализаторов.
Передача данных осуществляется в формате JSON с последующим фронтендом контента на устройстве клиента.
В проект интегрирована база данных PostgreSQL.
Содержание проекта включает два приложения:
* materials - включает базовый функционал для записи и отображения данных по доступным курсам и урокам;
* users - предусматривает регистрацию и авторизацию пользователей.
Передача и получение данных доступны исключительно авторизованным пользователям. Для решения отложенных и периодических задач установлено Celery с использованием брокера Redis.
Реализация проекта не окончена, что отмечено в соответствующих настройках модуля settings.py.
## Пример использования
После запуска сервера можно открыть доступные отображения, указав соответствующий запрос в адресной строке. После завершения работы необходимо закрыть сервер стандартной командой в терминале.
